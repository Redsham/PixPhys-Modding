# Примеры модов PixPhys

Эти примеры рассчитаны на текущий формат `Modification.json` и Mod API 1. Для Lua требуется обновление PixPhys с поддержкой Lua-модификаций и проверенных пакетов.

- **CSharp/Beacon**: собственный предмет, компонент Unity, сохраняемое поле и действие в контекстном меню.
- **CSharp/ResourceSpeaker**: загрузка спрайта и звука из папки мода.
- **Lua/HeatPlate**: предмет с управлением температурой, Lua-модулем и сохранением настроек.
- **Lua/PulseThruster**: собственная физическая логика на фиксированном шаге симуляции.

Скопируйте одну папку примера в `GameData/Modifications/`. Запустите игру, откройте список модификаций и выберите «Проверить версию». После включения предмет появится в каталоге. Действия примеров доступны через контекстное меню предмета.

Новая версия требует нового подтверждения. До подтверждения обновления игра использует предыдущую разрешённую копию. Для замены уже загруженной версии нужен перезапуск.

C# работает внутри Unity и имеет права процесса игры. Проверка кода и подтверждение версии не создают песочницу. «Полная совместимость C#» отдельно разрешает обойти дополнительный фильтр для конкретной версии. Публикуйте моды из сеанса, в котором C#-модификации не загружались.

Lua имеет ограниченный игровой API и собственное хранилище. Прямого доступа к файлам пользователя, процессам и Steam нет. Поскольку интерпретатор работает внутри игры, его лимиты не равнозначны изоляции отдельным процессом.

Пути к ресурсам должны быть относительными и вести внутрь пакета. Старые C#-моды текущего формата продолжают использовать `Main(Modifications.Modification)` и `Prop.Register`. Отсутствующее поле Runtime означает C#.

Не меняйте имена зарегистрированных C#-предметов и сохраняемых типов без миграции. Идентификаторы Lua-предметов зависят от источника пакета: переезд локального мода в другую папку или публикация под новым Workshop ID меняет их.

[Описание Lua API](docs/Lua-API.md) и [ограничения совместимости](docs/Compatibility.md). Проверка структуры пакетов: `python3 tools/validate_examples.py`.

Примеры эпохи 0.1 оставлены в `Archive/0.1` как история. Их API устарел, адаптеры для него не добавляются.
